# MQTT2IR — Home Assistant HA App Repository

[![Open your Home Assistant instance and add this repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fspasemice%2Fmqtt2ir-ha-app)

Official Home Assistant HA App repository for **MQTT2IR**.

## Installation

1. In Home Assistant go to **Settings -> Add-ons -> Add-on Store -> Repositories**.
2. Add:
   `https://github.com/spasemice/mqtt2ir-ha-app`
3. Install **MQTT2IR**.
4. Configure MQTT broker credentials and start the app.

## HA Apps in this Repository

- [MQTT2IR](mqtt2ir/) - Web UI for IR bridges with learning and MQTT discovery.
